## 요청 내용

사용 안내서 사이트(https://seonmikii.github.io/gdc-claude-plugin)에 #850(v0.10.0)에서 추가된 도구를 반영한다. PR #37에 같이 넣어 머지 시 함께 배포되게 한다.

## 배경

사이트는 `main`에 `site/**` 변경이 push될 때만 배포된다(`.github/workflows/pages.yml`). PR #37은 `site/`를 건드리지 않아 안내서가 v0.9.1·도구 34종에 머물러 있다.

## 수행 계획

- 하단 버전 표기 v0.9.1 → v0.10.0
- 도구 섹션 도입 문구 34종 → 54종
- 기존 그룹 보강: 조회(`search_tasks` 태그·검색 범위), 생성·수정(`create_task`·`update_task` 태그·주간 회의 공유, `move_task_project`·`bulk_update_tasks` 추가)
- 새 그룹: 태스크 연결(4) · 주간 업무·캘린더·일정(5) · 리소스 예약(5) · 고객 접수(4)
- 공통 입력 규칙에 `#번호`로 태스크 지정 안내 추가
- 한국어/영어(`data-en`) 병기 유지
