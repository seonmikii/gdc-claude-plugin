## 배경

- 새 대상(#841·#848·#818·#819·#797·#732·#845·#812·#847)은 GDC 상태 `개발 배포됨`이고 운영 번들에는 화면 문구가 없다(2026-11-25 확인). 캡처는 개발 서버(se.gemiso.com:11521)에서 했다.
- #560은 v2.11.5로 운영 반영된 건인데 노트에서 빠져 있었다.
- 태그가 없어 버전은 다음 번호 v2.11.6으로 적었다.
