- `feat` — 신규 기능
- `fix` — 버그 수정
- `refactor` — 리팩토링
- `ui` — UI/UX 개선
- `infra` — 인프라/설정
- `schema` — DB 스키마 변경

## 영역 범례

- `server/*` — 백엔드 (auth, api, convert, audit, workflow, license, ...)

- `db/*` — 데이터베이스 (schema, migration, ...)
- `infra/*` — 인프라 (docker, deploy, ...)
